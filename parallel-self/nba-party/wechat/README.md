# 整活NBA · 原生微信小程序工程

这是可导入微信开发者工具的 **WXML / WXSS / JavaScript 工程包**，不是 `web-view` 网页套壳，也不能在微信聊天中点开 ZIP 直接安装。

核心是娱乐测试：首页选 8／16／24 题 → 随机球场情境、点选自动跳题 → 匹配人物与本命海克斯 → 五人阵容、分支故事和海报。DIY 可创建名字、号码、口头禅、六维能力与自定义海克斯，保存到本机后加入自选队友；不会混入默认测试池或改写原始匹配身份。

## 导入

1. 解压 ZIP，在微信开发者工具选择“导入项目”，选择含 `project.config.json` 的目录。
2. 工程的 `miniprogramRoot` 已指向 `miniprogram/`。`touristappid` 仅为占位；用真实微信小程序 AppID 创建项目后，替换该字段。无有效 AppID 时，访客模式能力以开发者工具实际支持为准。
3. 不需要 npm、服务端或在线资源。题库、计分引擎、人物、海克斯图与页面都在包内；存储仅在本机。
4. 先在开发者工具完整走通三种题量、返回改选、恢复进度、图鉴、DIY 增删改、自选五人、故事和海报，再分别使用 Android 与 iOS 微信真机验证。核对相册权限拒绝与允许两种情况。
5. 之后才可用真实 AppID 上传体验版、设置平台资料并提交审核。当前包没有被上传或通过微信平台审核。

## 当前验证边界

- 构建检查所有原生页面路径、JavaScript 语法、共用内容指纹及文件体积；运行文件未压缩总量按 2 MiB 主包预算检查。
- Node 中的微信 API 模拟只能验证状态和调用顺序，不能证明 WXML 编译、WebView／原生渲染或真机 Canvas 行为。
- **本环境没有微信开发者工具和实体手机，未生成开发者工具或真机截图。AppID 配置、开发者工具、Android、iOS、平台审核均待完成。**
- 相册写入只在用户点击“保存图片到相册”时调用；生成海报本身不申请相册权限。拒绝后提供提示，不自动打开设置。
- 图像在分发时技术转换为原生 Canvas 可用的本地 JPEG，不改原始画稿和人物映射；来源与分发 SHA 见 `build-manifest.json`。

## 重建

在上层 `nba-party/` 工程执行：

```sh
python scripts/build-wechat.py
node --test tests/wechat-structure.test.cjs
```

生成：`release/zhenghuo-nba-wechat.zip` 与 `release/wechat-build.json`。主包大小以构建报告为准，正式平台打包与性能仍须开发者工具和真实设备验证。

人物标签、对白、平行剧情和海克斯效果是娱乐二创，不代表本人发言、真实履历或背书。没有心理诊断、球技评级、账号系统、预约球场、支付、IM 或位置采集。
