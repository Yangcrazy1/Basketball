# V7：一本正经地离谱

风格参考是网友 DIY 卡的格式与反转句法。用户图中的“禁止 AI”属于图内恶搞文案，未作为开发指令。公开搜索找到 DIY 合集，实际查看了“得过且过”配图；文章正文返回403，没有继续访问。所有运行时图标重新生成，卡牌效果以本作创作为主，不声称收录网友原作全集。

语义链：实际反应 → 六维刻度与行为权重 → 平行人物 → 25 张恶搞卡候选 → 同类卡对应的五人分工。人物取65%向量贴合＋35%行为覆盖；卡牌取42%向量贴合＋53%行为覆盖，加最多5分人物风格加成。所有卡均需至少一个实际语义命中，AFK/甩锅类另设必要条件。结果不展示这些分数为科学准确率。

例如收集者/远程办公的8题组合中，以挂机、后撤为主会给出PDD＋泉水股东；同场景冲锋开送会转为开团/混乱类；收集者/审计组合中的经济选择会给出污渍＋第五位收集者；保护/治疗组合会给出Meiko＋你们四个别死。测试使用真实题目与选项，不从界面文字硬编码结果。

25个四幕剧场分别随机抽选，内部事件顺序保持；上一幕选择保留并附语义反应。收集者第一幕的四项选择直接改变第二幕问题。回看显示真正走过的问题分支。重开与续答、V7历史均保持可复现性。

首页在390×844首屏可开始；单题试玩不写历史，不冒充完整测评。25张卡的图鉴可预览完整文案。结果顺序为人物与恶搞卡、实际匹配证据、架空剧情、五人分工、折叠的六维面板。固定海报按钮保持可见。PNG海报使用同一人物、卡片、证据与阵容。

运行文件为一个自包含HTML，内嵌11张人物WebP图集与1张新的透明图标WebP。人物图像沿用V6并保持示意标记。无外部运行依赖、官方强化图标、后台或生成式AI调用。下载导出取启动时干净文档，不携带本轮答案。下载后需要能执行网页脚本的浏览器，在线HTTPS入口用于直接手机体验。
