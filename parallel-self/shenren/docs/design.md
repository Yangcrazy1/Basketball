# V5 规则与交付

主名称固定为「世界上另一个我」，神人战队是结果玩法，人数为五：你化身的人物与四名队友。联盟为首要主题，海克斯大乱斗为默认系列。

每次先按题量将六维题数分为相差不超过一题的配额，再在对应主题/系列内无放回抽题，打乱题序和选项。记录真实题目 ID、选项 ID 与显示顺序。下一新局若首题相同则交换，保证首题不同；刷新继续不重抽。

每维使用实际题数归一化为 0–100。人物接近分使用六维平均绝对差，只表示与编辑向量的距离。身份在天赋选择前由答题决定。组队使用五位置动态规划，固定身份人物、每个人只用一次、只放在其角色标签允许的位置，综合接近分、主副位置与天赋偏好选择四名队友。新局随机，完成后的同样答案与天赋不会偷偷随机换结果。

天赋三选一选项预先保存，重掷排除刚才的三项且本局只能用一次。天赋改变队友偏好与三维配件，不修改原始答题画像或身份。天赋是原创规则，非官方平衡数据。

平行剧情允许改写 S8 与飞科加里奥等时间线，页面明确架空。组队是故事之后的跨时间线招募，因此故事里的对手可以成为组队伙伴。

三维分身以立方体、椭球、多边形、圆柱等组成不同造型，进行三维旋转、透视、深度排序与明暗绘制。得分决定眼镜、背包与姿态等，天赋加入不同配件。2D Canvas 是投影绘制介质，不是将一张照片假装成三维。没有使用外部三维库或需要联网获取的模型。

离线 HTML 下载采用页面启动前的完整源文档快照，不把已经答出的结果或用户历史嵌入导出文件。题库、头像图集、照片与全部脚本已内联。PNG 出图也不需要外部服务。
