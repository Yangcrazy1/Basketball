# V6 内容与匹配

主流程：选主题/系列及题量 → 随机抽取完整章节 → 四幕选择 → 答案自动匹配人物与海克斯 → 合法五人队 → 架空故事及可下载海报。

LoL 六维：上头、经济、风险、队友、操作、运营。每个选项有独立向量，另有 collector、gold、heal、protect、range、chaos、reset 等行为标签。选项 ID 固定，展示顺序随机，不用 A/B/C/D 位置记分。分数用本轮每维可达的上下限与选项均值校准，避免章节本身倾向影响中点；这不是心理学常模。

人物匹配取编辑向量距离；真实强化匹配采用 78% 向量贴合与 22% 实际选中标签覆盖，稳定排序，可重复。页面引用的依据必须来自本轮真实答案。天赋是娱乐风格匹配，不读取实际对局英雄/版本强度，不能据此声称是竞技最佳构筑。

五人组队固定本人身份在允许位置，再以位掩码动态规划求四名队友，保证五人唯一且分位合法。篮球和网络主题沿用独立旧六维，不混入联盟的新轴；补给标明为原创。

每个联盟章节有固定四幕。章节顺序及选项随机；内部四幕保留因果时间顺序。后幕显示上一幕真实回答，允许返回修改。并非生成式剧情模拟器，题目与故事为预先撰写，不联网调用 AI。

交付：无外部运行依赖的单文件 HTML，11 张 WebP 图集、16 张真实 PNG 图标内嵌。离线导出取启动时干净文档，不携带个人答案；V6 本地存储隔离旧版本。当前文件预览器不执行脚本的限制由线上 HTTPS 网页解决。
