# 平行宇宙的另一个我 · V14 平行人生

依据 [用户开发文档](v14-user-spec.md) 在 `bf9fa32` 的有效 V13 分支上增量开发，发行编号 14，活动答题 schema 13。主推清单全部实施，候补及待核项不进入玩家活动池。

## 内容和匹配

- 活动人物 58 位：联盟 21、篮球 20、抽象 17。新活动数据删除任正非；加入德雷蒙德·格林和恶鼠／张梓祎，分别归 NBA、民间篮球。
- 人物代表卡 137 张、143 条人物归属；六张共享卡各只保存一次。另保留审核后的 37 张通用场景卡，共 174 张。26 张去重后的候补卡仅供内容审阅，不参与随机推荐与奖励。
- 新写 232 道人物情境题，与 100 道审核保留题组成 332 道活动题。联盟按完整四幕抽取；其余主题兼顾六个维度。公开题面和章节标题不显示内部匹配人物 ID。
- 原始人物分数继续来自实际选择；热门排序优先只在相近候选内生效。卡片证据精确到题目及选项，同一行为标签不会让无关选项触发新卡。
- 收集者恢复为共通情境，原文与五把真实装备图标保留：当你四个队友都出了收集者，你的商店里只有收集者。

人物标签从同一份代表卡 ID 派生，点击标签与卡片进入同一详情。别名独立保留；阿水／哥哥／JackeyLove、污渍／Uzi 均为单一人物。

## 可选择的故事

58 位人物各有六幕完整故事，每条包含两次选择与两个不同结局。第一处选择改变中途道具、配角反应或后果，第二处选择改变收尾事件；每次只展示当前节点。五组主样板及格林、恶鼠均有直接试玩链接。

测试结果只获得实际匹配的一张海克斯，图鉴代表卡不会自动全部送出。故事明确奖励的卡会记入本局背包；未获得的卡使用普通事件变体，不能显示能力发动。返回改选时通过动作历史重放，撤销后续奖励；刷新后可继续。身份页、故事与三类海报读取对应本局的实际获得记录。

故事试玩从零张卡开始，不伪造测试身份。格林的战争践踏以灯光踏板和暂停牌表达，无伤害画面；格林×恶鼠等联动标注虚构二创。学历、收入及真实手机品牌不用于现实阶层评价；峰哥剧情讽刺伪分析，不作现实诊断。

## 界面与美术

- 默认浅暖纸色、苔绿主色，保留夜间配色。首页以三步引导、三个世界、三种题量和一个主要按钮组织；人物／海克斯为两个次要入口。
- 三幕为全新独立 4:5 绘本原稿：普通的一天、触镜、三个世界。同一主角与衣服连续；前端排文案，支持上一步、跳过、随时重看和减少动态效果。后两张顺序预加载，图片失败时继续／跳过仍可用。
- 图鉴默认两列、完整集合可纵向浏览，支持主题筛选与别名搜索。人物放大、完整卡片效果、共享归属、关闭返回、滚动与焦点保持均在同一套组件中完成。
- 全界面控制最小触摸高度 44px，约 240ms 轻淡入；按题自动下一题。底导航与故事／答题专注模式分开，底部操作区避开安全区。
- 新增格林和恶鼠的已核对照片参考漫画；16 格专属道具图集覆盖毕业帽、反向学历阶梯、盒饭、手机／座机、心理书／扫描、纸牌／咖啡／起立、1.5 领奖台、公式、灯光踏板、八角笼。其余卡按具体物件复用已有图标，逐卡理由见 `content/v14-art-map.json`。

照片和账号头像来源边界见 [头像参考](v14-portrait-references.md)。尼达、伊利沿用已核对官方账号头像的既有边界，不声称全部真人面孔均获独立确认；公开参考不等于商用授权或本人背书。

## 历史、构建与小红书

schema 10、11、12 的数据及引擎均冻结，旧档案用对应引擎回放，保留原身份、分数、阵容及队名。新版本仅发布到 `/v14/`，旧根入口与 V11／V12／V13 保留。

小红书包根目录 `index.html`，运行资源全部本地提供，四个经典外置脚本按 ES2017 解析。原稿 PNG、审阅界面和截图不进入小红书包。多版本历史数据保留以保证旧档案重放；单文件超过建议值的体积风险、实际字节数、目录／ZIP 审计以 `docs/xhs-validation-v14.json` 为准。
