# 在线入口加载修复

用户反馈“打不开”后重查，原 URL 在云端返回 HTTP 200，但每次打开必须先读取 10,558,414 字节的单文件 HTML。云端通过不能证明用户手机网络能访问该域名，也不能确定这就是用户遇到的原因。

在线版改用 2,011 字节 HTML、带内容哈希的脚本/样式和包内相对图片路径。开场实测请求体积 1,165,022 字节（本地 HTTP 无压缩）；人物 atlas 仍在使用时创建。完整 10.6 MB 离线 HTML 与已审计小红书 ZIP 的内容不变，在线页面下载动作指向完整离线文件。

六项本地移动视口回归覆盖开场请求预算、三主题答题与身份/组队流程、PNG、自选组队、完整离线下载以及数据脚本被阻断时的可见重试提示。公开部署校验见 web-verification-v10.json。

新增 /play/ 入口，避免旧页面缓存；原根入口同步使用轻量版。若用户仍无法连接 github.io，需要用户的具体提示来区分网络域名可达性与浏览器问题，本次未把云端连通性当成手机连通性。尝试的独立托管备用来源被当前环境拒绝访问，未绕过网络策略，未将其作为可用链接交付。
