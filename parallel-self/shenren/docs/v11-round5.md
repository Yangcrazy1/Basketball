# V11 第五轮：验收候选

离线文件：https://yangcrazy1.github.io/Basketball/preview/v11/r5/world-another-me.html

本轮未替换V10正式入口，未制作正式ZIP。截图是393×852 Chromium手机视口实测，非实体手机拍摄。

## 改前／改后

| 项目 | V10 | V11候选 |
| --- | --- | --- |
| 默认名单 | 95人，所有人参与 | 联盟20／篮球10／抽象10，同一enabled配置驱动图鉴、匹配、补全和自选 |
| 首页 | 三幕后进入长功能页，默认16题 | 一张原创简洁插画，三个入口，默认8题，16／24折叠 |
| 图鉴 | 窄弹窗，12项分页 | 全屏两列大卡，不分页，昵称／标签搜索，返回恢复状态 |
| 人物卡 | 部分人物一张，多人共享 | 40人各3张独占，120张；另36张通用／联动 |
| 题库 | 348题全部默认 | 审阅全部旧题，当前328题；联盟120题为30个四幕，日常／名场面／简单游戏60／30／10 |
| 身份匹配 | 部分章节可给特定人物额外20分 | 原始分40%六维接近＋35%实际行为＋25%相关情境；重点人物仅在落后最高原始分≤5时加最多4，显示原始分 |
| 旧记录 | 同版计算 | 冻结V10数据与引擎，保留退出人物和自选阵容原结果 |

匹配规则中的相关情境只读明确的问题ID与实际行为，不是人气加分。每个角色的answerAffinities可复核。4500组有效8题作答均为真实题库抽样，40个人都至少成为过一次第一名；可复现会话在[v11-reachability.json](v11-reachability.json)。不是人群分布或真人性格准确率报告。

80张专属卡可作答触发，各有至少两道相关题可供证据；40张为人物自带赠卡，不参与“你选过”证据。没有触发专属行为时，结果使用实际作答触发的通用卡，另附身份三张卡。

## 验证

- 新引擎11项、冻结V10回归21项、平台存储契约2项，共34项通过。
- 12组浏览器检查通过：三主题×8／16／24题、别名、全量列表、返回路径、自动跳题／防重复点击、自选阵容、实际PNG下载、完整HTML下载、离线运行、旧人历史、资源加载与脚本异常。
- 320／360／393／430／1280布局检查无横向溢出，393px列表头像约170px、详情220px；实际截图位于预览screenshots/。
- 首屏入口约2KB，首屏所需资源约1.6MB（未压缩），人物／卡图按需加载。阻断数据脚本时显示重试入口。
- 小红书仅构建资源暂存目录并通过ES2017解析及现有平台契约测试，没有上传、打包正式ZIP或实体小红书验收。
- 发布后公开HTTPS检查见[public-preview-v11.json](public-preview-v11.json)。
