# V11 第四轮：人物专属海克斯

40人各3张独占卡，120张；另有36张通用／联动卡，不计入最低数量。所点名12位样板也全部完成，内容位于 content/v11-personal-cards.txt；双向owner/签名引用与覆盖见 v11-card-coverage.json。

改前：只有部分人物一张专属卡，常有多人共享。改后：每位启用人物恰好三张独占卡，代表梗／反转／日常各一张，包含触发场景、效果、包袱、图像构思和规则。

原卡稳定ID复用，例如 collector-union、double-laugh、square-lecture、not-a-loss、personal-dailanzi；旧记录另用V10快照重现。

80张为作答触发卡，规则同时限定相关问题ID和行为，每张至少两道相关题可提供证据；40张为身份赠卡，明确不生成作答证据。未匹配到专属行为时用实际选项触发的通用卡；结果仍附赠人物三张卡，不能伪造“你选过”。

125张新物件组合矢量插图，饭碗／鼠标、学士帽、麦克风／卷轴等，保留五把真实收集者的原图标组合。图源分类与哈希位于 assets/v11-card-art-sources.json。矢量为本作原创绘制，不冒称网上梗图或官方图标。
