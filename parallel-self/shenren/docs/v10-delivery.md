## 小红书适配

使用用户指定 `minitool-zip-builder` 1.8.0，下载到 `.codex/skills/`，读取 SKILL.md 与全部六项 reference；先读冻结 API 基线，再读取 2026-10-22 更新的在线文档（2026-10-23 核验）。已向用户播报公开新增的窗口信息、定位、振动、陀螺仪、关注作者及 AI 文本生成内测能力。

交付包只接入业务所需的平台存储、安全区/原生顶部按钮避让、临时图片文件和用户点击后的存相册。没有主动发笔记、关注操作、定位、AI 调用、平台登录或上传。

- 根目录唯一 `index.html`；4 个相对路径经典脚本，图片均为包内文件。
- 去除内联脚本、下载及外链跳转；来源以可选中的离线文本展示。
- 直接以 ES2017 编写；用 Node 已带的 Acorn 按 `ecmaVersion: 2017` 解析最终四个脚本。没有增加 Babel/core-js/npm 构建依赖。
- image.decode、Canvas roundRect、dialog 提供局部检测与回退；SVG 同时使用 href 和 xlink:href。
- CSS 使用 grid-gap 基线、实际测量 Flex gap 后的局部 margin 回退、比例盒、focus、普通字号和安全区回退；移除 :has/inset 的唯一依赖。
- 人物/海克斯分页、搜索防抖，头像 atlas 按需创建并清理；PNG 输出后释放缓存。没有 3D、WebGL、Worker、WASM 或外部资源请求。
- Storage API 以去掉编译序号后的客户端版本判断；原生写入串行，兼容浏览器存储失败。仅迁移成功读取为空的 native key，原生读取失败时不覆盖数据。
- 生成海报后由明确点击触发 writeTempFile → saveImageToPhotosAlbum，不持久化临时路径。

最终审计的体积、SHA 与静态检查结果见 `xhs-validation-v10.json`。包体超过 2 MiB 建议值，主要为离线人物漫画和剧情插画；低于 10 MiB 硬上限，无超限 Base64 或大文本文件。
