## 保持一致的记录

原58位人物的计分向量、问题、卡片、故事和曝光设置不变。新候选加入后，新版同一组答案的领先者可能改变；旧记录继续通过其对应冻结引擎回放，保持原身份、分数和阵容。

新版本读取 schema10／11／12／13 四版冻结快照；尤其 schema13 已获故事卡及结局按冻结故事 API 重放，能继续、回退和改选。旧V14故事存储key保留，新版分开保存并兼容旧进度；人物、故事、结果及海报读取同一局实际背包。

原入口和 `/v14/` 保留，新版只发 `/v15/`。正式源码与公开产物记录在 `docs/v15-deployment.json`。

## 来源与验证边界

蔡徐坤取公开官宣报道的人物照片为面容参考，经典背带裤与舞台动作是本作漫画再创作。369采用明确点名白家浩的公开合照与赛事照片交叉核对，不混用其他选手。

369拉扯、酒桶梗仅记录已找到的公开索引，不声称完整观看原片或核实新台词为本人原话；摇骰子直接出处尚未定位，元数据为 `partial_context_only`，说明只取得999状态比喻的报道背景，卡片机制属原创二创。该项在审阅页的来源待核筛选中可见。

小红书包是可上传的静态 ZIP，根目录 index.html、全部运行资源本地、四个经典外置脚本按 ES2017 校验。名称介绍、原稿PNG及审阅页不放入原生包。沿用同日已核对的小红书公开规范及原生缓存、安全区、临时文件／相册实现。

**仍待用户：将同一 ZIP 上传创服平台，先完成平台模拟器完整功能验证，再分别用 Android 与 iOS 真机扫码。Chrome61 CSS 与真实性能未实测。** 浏览器及SDK模拟不代表平台原生验收或审核通过。包体和大文本建议值警告以 `docs/xhs-validation-v15.json` 为准。
