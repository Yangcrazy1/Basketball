# 世界上另一个我 · V6 海克斯名场面

手机直接体验：https://yangcrazy1.github.io/Basketball/?v=6-hex 。页面底部可下载完整单文件 HTML（约 4.4 MB），所有头像、题库和真实强化图标均内嵌，无 CDN、账号或后台。下载后的 HTML 仍需由支持 JavaScript 的浏览器执行；系统文件预览器不一定支持。

## 这一版

- 移除三维模型。44 个主题条目、42 位人物全部换成新卡通头像；37 位有已检查的公开参考图像，5 位标明为角色示意。王老菊使用账号卡通形象作为参考，非本人照片。
- 联盟 84 道题组织为 21 个四幕小剧场：海克斯 48、峡谷 36。每轮抽 2 / 4 / 6 个剧场，对应 8 / 16 / 24 题。随机剧场与选项，保留剧场内部事件顺序；新局首题与同系列上一局不同。续答保持原题与选项。
- 四把收集者、没有 R 的基础技能、潘朵拉开箱、桥头奶站、雪球驾校、平行 S8 等连续情境。后幕保留上一幕的实际选择，返回修改后同步更新。
- 每个联盟选项提供多维信号与行为标签，挂机和开送不是相同评分。六维刻度以本轮题目的可选信号范围和选项均值校准；50 为该轮选项均值，不是人群常模。
- 答题后自动给出人物、真实海克斯参考、匹配依据、另两个可能，以及你＋四名队友的合法五人分位。无需再挑一个虚构天赋来决定结果。
- 16 枚真实端游海克斯大乱斗强化：名称/稀有度核对 CommunityDragon 16.21 的 KIWI 池快照；真实图标和机制参考 LoL Wiki。游戏效果与本作人格解读分开显示，排位结果说明其为大乱斗风格参考。
- 新的 1080×1920 人物×海克斯×五人阵容 PNG 海报。夜场紫 / 奶油两套配色、历史 12 条、离线 HTML 导出。
- 篮球与抽象网络保留各 36 题及原创主题补给，共 156 题。所有故事是架空创作，非真实赛史、人物原话或心理评价。

## 构建与验证

```sh
python build.py
node --test tests/engine.test.cjs
python tests/browser-check.py
```

`build.py` 仅依赖标准库，输出 `dist/world-another-me.html`。Node 测试覆盖题库/章节随机/计分/实际选择上下文/真实强化快照/五人位置/完整离线打包。浏览器检查需要 Playwright、Pillow、`/usr/bin/chromium`，报告在 `docs/browser-check-v6.json`。

`tools/v6-content.py` 和 `tools/pack-portraits.py` 是这次内容制作脚本，使用工作环境里的研究资料及图像生成原稿，不是日常构建前置依赖。生成后的全部 WebP、16 枚原始 PNG、来源及客户端快照均已入库，普通构建不需要联网。

## 图像与机制出处

头像映射和校验：`assets/portrait-atlas.json`；参考来源：`image-sources.json`。五位示意头像为 Meiko、Letme、papi酱、白客、峰哥；没有把通用示意声称为本人参考重绘。

强化记录：`assets/augment-sources.json`；游戏名称、稀有度及 KIWI 池的独立快照：`assets/reference-metadata/`。最新版本中的“量子计算”因 Wiki 标记停用未参与推荐。“掀桌”尚未核实对应的端游正式名称，因此未伪造同名官方天赋。截图中的“代码工作量翻倍”是用户提供的恶搞视觉参考，不是游戏效果。
