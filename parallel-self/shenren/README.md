## 本版变化

- **点选即下一题**：点击 A / B / C / D 后记录选择，短暂显示反馈便自动前进。保留返回改选；连续点击或旧题按钮不会给新题误记答案。离开过渡动画后也能从下一道已保存的题续答，最后一题自动揭晓。
- **联盟不再分入口**：首页只保留一个英雄联盟板块。内部章节元数据用于保持故事连续，不作为用户可选子模式。常见梗附短解释，题面移除“走A、线权、斩杀线、CD”等说法；新增S赛、IG冠军回忆、对线避险、小地图和冠军皮肤等场景。
- **恢复必须出收集者**：“队友四个出了，我能不出？”恢复到正式题与首页试玩。匹配后展示五个真实收集者图标、“必须出收集者”卡和实际作答证据。
- **人物 × 专属海克斯**：每个人物都配置对应联动卡；结果只有实际答案满足卡牌前提时才显示“已激活”。联动面板引用真实选择，人物卡也可查看其专属卡。NBA 与抽象题同样参与行为匹配和证据生成。
- **新人物与画面**：加入华子、文班亚马、李子柒，基于已检查的公开照片卡通化；新增原创虚构人物“摇摆导演”。新增16个NBA/创作主题图标。联盟继续使用27个真实游戏图标排布。
- **本期网络热梗**：参考已读取的2026年公开整理，加入摇一摇二创、豆包型人格、做完你的做你的、进城办事、不讲不讲、活人感、爱你老己等情境。标明2026-10-23整理日期，保留出处；离线版是编辑快照，不自动抓取实时热榜。无整段文章、视频、音乐或完整歌词复制。
- **保留功能**：两套配色、合法五人分位、架空S8/加里奥/GOAT剧情、最近12次本机记录、1080×1920 PNG海报、完整单文件HTML。美国讲师与3D模型继续移除。

40位人物头像有公开照片参考，5位为明确标记的示意头像，1位为原创角色。说明见 `image-sources.json`；本期热梗与新素材记录见 `docs/v9-references.json`。人物倾向、故事与卡牌效果均为本作娱乐创作。装备PNG源文件与哈希见 `assets/game-icon-sources.json`。

## 构建与验证

```sh
python build.py
node --test tests/engine.test.cjs
python tests/browser-check.py
python tests/public-web-check.py
```

构建只用 Python 标准库。引擎检查用 Node，浏览器检查依赖 Playwright、Pillow 和 `/usr/bin/chromium`。独立使用 `world-otherme.v9` 本机存储，保留旧版本记录。

核心内容在 `src/data.json`，匹配、答题提交与联动在 `src/engine.js`，界面和海报在 `src/app.js`。`tools/v9-content.py`、`tools/v9-interface.py` 是从V8升级的制作脚本，不是普通构建前置；构建直接使用已完成源文件。

验证报告为 `docs/browser-check-v9.json` 和 `docs/web-verification-v9.json`，覆盖单次点选、防连点、改选、三板块各题量、人物联动、真实下载和导出文件断网载入。测试范围是 Chromium 手机尺寸，不是实体手机硬件；云浏览器管理策略阻止 file:// 导航，离线检查以导出内容断网载入进行。
