## 本版内容

- **真实图标再创作**：27 个 Riot Data Dragon 16.21.1 装备 / 召唤师技能 PNG。五把收集者、六把无尽、三顶帽子、双金身、五个心之钢等直接重复原图标。36 张联盟恶搞卡全部使用这些图标重新排布；效果与吐槽为本作创作，不是官方强化或出装推荐。
- **题目回到对局**：204 题，其中联盟 132 题、33 个连续四幕情境（海克斯 80、峡谷 52）。会议桌、董事会、审计等题面已替换为出装、灰屏报信息、团战复盘、守塔和资源决策。
- **新名场面**：小虎二段笑、滔博陀螺抗压局、闪现撞墙、金身时机、雪球二段、重复出装、探草和抢龙庆祝。二段笑 / 陀螺入口有出处、改编说明和可直接进入的计分题。陀螺按 TES 队标与被动挨打梗改编，不声称是某位选手的旋转操作。
- **匹配相关性**：实际答案决定六维风格、人物、恶搞卡和五人分工。专属反应有前提限制：未选择笑、金身或视野等行为，不会推荐对应的限定梗卡。卡面展示两条实际作答证据。人物倾向均为本作娱乐设定。
- **每局随机**：8 / 16 / 24 题抽取 2 / 4 / 6 个不同剧场，剧场顺序与选项随机，同一剧场内部按四幕推进；重开首题改变。名场面入口明确先体验指定四幕，再随机补齐；续答保留原题与选项。
- **手机与海报**：夜场紫 / 奶油两套配色，首屏可开始，新增装备梗插画与名场面入口。网页与 1080×1920 PNG 海报共用图标布局，海报中的收集者也实际绘制五次。
- **保留功能**：42 位人物、44 个主题条目，合法上 / 野 / 中 / 下 / 辅五人队，架空 S8 / 飞科加里奥 / GOAT 剧情，篮球与抽象网络各 36 题，记录只留本机。美国讲师与 3D 模型已移除。

37 位人物头像有公开参考，5 位为明确说明的示意头像，见 `image-sources.json`。装备图标归原权利方所有；数据与逐图 SHA-256 见 `assets/game-icon-sources.json`。首页横幅是参考四种装备图标生成的插画，卡牌和海报使用原始 PNG；创作及名场面来源记录见 `docs/v8-references.json`。

## 构建与验证

```sh
python build.py
node --test tests/engine.test.cjs
python tests/browser-check.py
python tests/public-web-check.py
```

构建只用 Python 标准库。浏览器检查依赖 Playwright、Pillow、`/usr/bin/chromium`。本版使用独立的 `world-otherme.v8` 存储，旧版记录保留。

核心文件为 `src/data.json`、`src/engine.js`、`src/app.js`、`src/style.css`；真实图标在 `assets/game-icons/`。`tools/v8-content.py` 和 `tools/v8-interface.py` 是从 V7 升级时的制作工具，普通构建直接使用已完成的源文件，无需重新运行制作脚本或联网。

15 项引擎检查覆盖随机抽题、答案语义、不同梗卡、合法五人分位、真实图标哈希和复制数量。浏览器报告见 `docs/browser-check-v8.json`，公网报告见 `docs/web-verification-v8.json`，包括手机尺寸排版、真实 PNG / HTML 下载、导出文件断网载入和拒绝存储时的完整流程；当前云端 Chromium 的管理策略阻止 file:// 导航，此项在报告中单独标记。测试范围是 Chromium，不是实体手机硬件。

本次交付已通过 15 项引擎、14 项浏览器与 6 项真实公网 HTTPS 检查。公网首页和实际下载的 HTML 与发布文件 SHA-256 一致：`d99f312ab22eb6463cd8ce12a55dff4c8c6f6d80a54702f5c3cdab5e7c74c7b3`。
