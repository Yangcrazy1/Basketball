# 世界上另一个我 · V5 海克斯优先版

在平行宇宙成为另一位主角，改写结局，再和四位队友组成五人战队。当前重点为英雄联盟：默认海克斯大乱斗，另有峡谷排位；篮球和抽象网络为次要入口。

**手机网页版：[直接进入](https://yangcrazy1.github.io/Basketball/?v=5-hex)**。页面底部「下载离线网页」会保存一个完整 HTML 文件，无需安装 APK。在线版是主要打开方式；离线文件仍需支持 JavaScript 的浏览器，部分文件管理器预览不执行脚本。

## 当前内容

- 联盟 84 道原创情境：海克斯 48、峡谷排位 36。另有篮球、抽象网络各 36 题，全库 156 题。
- 8 / 16 / 24 题随机抽取，覆盖六个维度；题序与四个选项独立打乱。新局首题与同系列上一局不同，续答保留本轮题目。
- 15 个联盟角色条目，含 Uzi、销户、大司马、TheShy、Faker、厂长、JackeyLove、Doinb、PDD、小明、Meiko、Letme、宁王、Knight、宝蓝。全主题 45 个角色条目。
- 先认领「我的平行宇宙身份」，再展开架空人生。例如平行 S8 在嚎哭深渊开决赛，污渍击败飞科的加里奥，改写结局并接下 GOAT 剧本。这是刻意架空，不是真实赛史。
- 12 项联盟整活天赋，三选一、每局可重掷一次。选项与重掷次数可续存。效果为本作原创组队与造型规则，不复制官方数值或宣称对应现行游戏版本。
- 你化身的角色固定，四名队友按得分与天赋组合；五人不重复，严格满足各自的上单、打野、中单、下路、辅助标签。大乱斗中的这些标签表示选手分工，不宣称地图实际有五条分路。
- 大司马、Uzi、小虎的头像已依据查看过的真实参考照片重新生成，保留眼镜、脸型、发型等识别特征。有来源的其他人物用参考原图；未重绘的角色用明确的文字徽章，不以同一张通用脸冒充本人。
- 得分与天赋生成原创低多边形三维分身，支持 360° 拖动旋转、俯仰、双指缩放、按钮旋转、自动旋转与 PNG 截图。是有真实三维顶点、面和深度投影的模型，不是旋转一张平面头像；也不是真人扫描。
- 夜场 / 奶油两种配色；历史档案、回看答案、1080×1740 身份与战队图片、本地三维截图和离线 HTML 下载。

## 运行与构建

运行期间无需后端、登录、AI 接口、CDN 或 WebGL。全部脚本、数据、图片和三维渲染代码都在约 1.8 MB 的单文件内。三维使用软件网格渲染，兼顾不支持 WebGL 的手机浏览器。

```bash
python3 build.py
node --test tests/engine.test.cjs
python3 tests/browser-check.py
```

Python 构建只用标准库。浏览器检查需要 Playwright、Pillow 与 `/usr/bin/chromium`，自动创建随机端口并验证实际下载。

源码：`src/data.json` 为题目、角色、主题与天赋；`src/engine.js` 为抽题、计分、架空叙事和五人分位；`src/toy3d.js` 为三维网格与交互；`src/app.js` 为网页流程。没有复用此前第三方存储模块，当前使用独立的本地存储适配。

最小微信迁移保留数据、纯 JS 引擎与三维模型逻辑，重做 WXML/WXSS、存储和微信 Canvas 交互。HTML 不是可直接提交的小程序安装包。

## 验证与范围

12 项逻辑测试、15 项本地浏览器检查，以及 10 项真实公开网址检查均已通过，记录在 `docs/`。公网 HTML 与本地受测成品的 SHA-256 一致，并已验证实际 PNG / HTML 下载。覆盖随机分层、系列题池隔离、稳定选项 ID、五人正确分位、天赋与身份的边界、360° 旋转、两种配色、五种宽度、PNG 与离线 HTML 实际下载、刷新续答和禁网运行。

没有连接实体手机。浏览器移动视口的验证不等于在所有手机或文件预览器里都已验收。得分与人物向量是编辑设定，非心理准确率；剧情、原创角色台词与虎扑式评分不是真人发言、平台评分或官方合作。

图片参考与重绘关系见 [`image-sources.json`](image-sources.json)。参考图片的商业授权尚未全部确认，不能将原型体验当作商业发行许可。原始照片未裁剪、改色或移除水印，卡通图由图像工具依据这些参考另行生成。
