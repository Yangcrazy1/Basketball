## 决策

**微信产品选择“基于现有项目改造”；当前用独立、单文件 H5 Demo 验证玩法。**

首选工程参考为 [HalfSweetLemon/sbti-weapp](https://github.com/HalfSweetLemon/sbti-weapp)。它是原生微信小程序，代码 MIT、无运行时第三方依赖，已有答题、续答、进度条、结果页和本地存储。源码的 Node 测试 25/25 通过；微信开发者工具与真机尚未运行，不能将这些测试等同于已上架可用。只有两次提交，属于早期小项目，预计由我们自行维护。

Demo 已实际复用该项目的 `utils/storage.js`，未修改其实现，通过浏览器适配器提供存储接口，并保留 MIT 声明。其余题库、六维计分、人格叙事、角色示例、界面和 SVG 图形重新设计。Demo 不是已完成的微信小程序移植。

不直接照搬：目前核查的项目没有同时提供“原创宇宙叙事 + 六维画像 + 四领域角色库 + 微信原生交付”的完整方案。为一个小型验证版引入登录、数据库、管理后台或 AI API，反而增加部署和调试成本。

## 最简单的 MVP

暂定名：**另一个我 · ELSEWHERE**。一句话：18 个平行宇宙情境，找到你的另一个人生，以及四个世界里与你气质相近的人物。

1. 首页：开始测试、继续未完成测试、查看上次档案。
2. 答题：18 题（6 维各 3 题，含反向计分），每题四个具体选项，进度条、返回改答案、断点续答。
3. 人格：8 个原创人格原型，另设均衡时的“多面旅人”；六维雷达图、平行人生、优势与成长提示。
4. 匹配：网红 / 体育 / 动漫 / 游戏，四类各 16 个示例角色，共 64 个；首页角色图鉴、各类 Top 3 / 全部匹配和匹配理由。
5. 留存：本机上次结果；截图分享、PNG 结果卡（浏览器允许时下载或分享），无账号与后端。

配色提供「星雾紫」与「森屿青」，顶部切换并记住偏好；页面、SVG 和 PNG 结果卡同步换色，不清空答题进度。

六维为社交能量、探索欲、共情力、行动力、秩序感、表达欲。原题分为 1–4，反向题转换为 5−原分；各维三题均值线性映射为 0–100。人格/角色分使用归一化曼哈顿距离：`100 × (1 − Σ|用户维度−模板维度| / (6×100))`。分数是“与编辑设定的模板接近程度”，不是匹配概率、明星真实人格或心理诊断。相同答案稳定产生相同结果。

真人与虚构角色的向量均是 Demo 人工设定，用来测试交互，未被实证验证。仅展示文字名称与原创图形，无明星照片、IP 图像或背书。结果理由说明接近的两维，也能查看差异最大的一维。正式发布需单独核实内容与素材使用权；如果取得授权，也可扩展角色库。

## 后续微信落地

阶段 A（本次已交付）：离线 H5 验证题目、叙事、四类匹配与分享图，零服务器、零 API 费用。

阶段 B（下一开发阶段，粗估 2–4 人日，不含审核与内容返工）：按 MIT 保留署名，基于 sbti-weapp 工程移植原创数据与纯 JS 引擎；把浏览器存储适配替换为 `wx` 接口；H5 DOM/CSS/SVG 视图重做 WXML/WXSS，雷达图和海报适配微信 Canvas；配置 AppID，在微信开发者工具与 iOS/Android 真机验收。**HTML 不可直接上传为原生微信小程序。**

阶段 C：小范围试测后再决定是否需要题库后台、云端记录、好友对比。首版无需 AI、登录、支付、聊天与数据库。若需要同时长期迭代 H5 和微信端，再评估迁移 uni-app 的成本，避免现在先引入完整跨端工具链。

## 手机打开与边界

`parallel-self.html` 内嵌所有样式、数据、脚本与 SVG，无 CDN、字体下载或接口请求。浏览器允许本地 HTML 执行脚本时可直接离线玩。部分 iOS 文件预览和微信附件预览不执行 JavaScript；这种情况下要用能运行 HTML 的浏览器/本地 HTML 查看器，或把同一文件上传静态 HTTPS 托管后用 Safari/Chrome 打开。不承诺任何文件管理器都能运行 HTML，也未提供已公开托管的网址。

本地存储被限制时自动降级为内存，仍可完成测试，但关闭后无法续答。浏览器不支持文件下载/系统分享时，结果图仍显示在页面内，可长按或截图保存。验证范围与测试结果见 README。
