# V4 结果逻辑审阅与可实施方案

本审阅只针对当前规则型娱乐产品，不把它当作经验证的心理量表。

## 现有逻辑的主要问题

1. **前 8 题永久冻结基础人格**：前 8 题只有社交 2 题、探索 2 题、共情 1 题用于 family；后续共情又答了 3 题，即使方向反转也无法修正最初标签。保存答题进度应保留原答案，而不应承诺人格标签永远不变。
2. **8 / 16 题维度题量不等**：按每维均值归一化是对的，但 1 题的维度数值同样画成 0–100，就容易被当成同等证据。现有 8 / 16 / 24 题不等于“低 / 中 / 高科学准确率”。
3. **硬切 50 放大微小差异**：49 / 51 形成不同标签，最接近的两型可能只差一题。直接把全部中间答案塞进“多面旅人”，又会让结果缺少记忆点。
4. **相似度百分比容易被当准确率**：当前是编辑设定向量的归一化绝对距离，不是“你有 91% 是某真人”。六个维度全部居中时，很多角色都可能拿到不低的分数。
5. **最低距离只能说明相似风格**：不能直接推出真实好友、恋爱、合作兼容。搭子推荐应明确是可解释的内容规则。

## 推荐的最小改动

### A. 让更长问卷真正修正结果

用所有已答题目计算六维均值；family 也使用当前完整问卷的前三维（social / explore / empathy）重算。保留 8 → 16 → 24 的题目嵌套与答题进度，但允许基础人格随补答细化，显示：

> “前 8 题看到的是初步侧面；新情境让画像更完整。答案没有丢失，标签可能调整。”

如果主代理希望尽量保留现有实现：仍生成三位 family 代码，但对任一维处于 40–60 时增加“邻近侧面”说明，不需要新增一个强制兜底人格。比较四/八个已存在 family 原型，展示最接近的两型；不能把中间值解释为医学意义上的不确定。

### B. 8 / 16 / 24 的产品承诺

- 8 题：**先看主角风格**。先给人物、三条特质和两条证据，提示“部分维度只参考 1 道情境”。
- 16 题：**展开做事子型**。补充行动 / 秩序的情境，展示“你如何把事情推进”。
- 24 题：**展开出场方式**。补充表达 / 边界场景，展示“台前还是幕后、顺势还是定界”。

题量标签应是“信息层次”，不要显示“准确率 60% / 80% / 99%”。若仍用 8 / 32 / 128，文案为“最多可形成的内容组合数”，不能说“128 种经验证人格”。

### C. 边界与反差处理

- family 路径保持可复现，无随机数；同样答案、同样题库得到同样结果。
- 若最接近两角色分差 ≤ 3 分，显示“**双主角彩蛋：这两种风格在你身上很接近**”，并列呈现两人，不伪造 90% 高确定性。
- 40–60 的维度用“**这次更接近中间位置**”；若同维度不同题反差大，用“**不同场景，你会切换做法**”。可由原始作答值的极差 / 方差得出，但不要称为量表信度。
- 各维显示“来自 n 道情境”，特别是速测结果。显示已答题量比伪造“置信度”更诚实。

## 主角 / 反差角色 / 搭子的明确排序定义

### 1. 本期主角：最相似风格

沿用六维平均绝对距离：`D(u,p)=Σ|u_i-p_i| / 6`，按 D 升序，平局按固定 id 排序。可显示“风格接近度 = 100 − D”，单位写“接近分”更清楚，不使用“准确率”。

文案：

> “本期主角：{人物}”
> “你在「{最近维度1}」「{最近维度2}」上的选择，与这个角色的编辑设定更接近。”

### 2. 反差角色：同一主题下的另一条路线

不要把全库最远的人包装成“你的黑暗面”。推荐选择**和用户核心特质有连接、但在一两个次要维度上明显相反**的人：

- 先挑至少 2 个维度差值 ≤ 20 的角色；
- 在这些候选中按“行动、秩序、表达”三维差值和降序；
- 排除主角，若无候选则不展示，或明确改为“最不同的设定”。

文案：

> “反差番外：{人物}”
> “你们都看重「{共同点}」，但到「{最大差异维度}」时会走向两条不同路线。”

### 3. 平行搭子：互补设定，不预测真实关系

用一个明确、固定、可解释的目标向量推荐：

- 保持探索、共情两维接近用户（共同语境）；
- 社交、行动、秩序、表达四维目标为 `100 − 用户值`（互补风格）；
- 按候选距离该目标的加权距离排序：探索 / 共情权重 1.5，其余权重 1；
- 排除主角和已出现的反差角色。

文案：

> “平行搭子：{人物}”
> “你负责「{你的侧面}」，TA 在这份设定里负责「{补充侧面}」。这是角色组合玩法，不预测真人关系。”

## 结果页建议顺序

1. **大幅卡通主角 + 一句话名场面联想**：首先让用户知道“我是谁”。真人名场面要有来源入口；无法核实的台词不要用引号标成真人原话。
2. **一句可分享总结**：例如“嘴上说别急，脚已经踩进传送门。”说明是系统原创文案，不伪造人物发言。
3. **三条有依据的判断**：从用户实际选项引用简短片段，映射到维度，不只贴几个空泛好词。
4. **基础人格 → 做事子型 → 出场分支**：速测锁定的部分可补答解锁，新增情境允许修正主角。
5. **主角 / 反差番外 / 平行搭子**：不同排序职责明确，不拿三张同义卡填充。
6. **六维图与每维题数**：折叠在“为什么这样判”内，避免图表抢走角色传播点。
7. **无登录保存海报**：截图 / PNG / 原生分享；海报带题量、版本、日期与娱乐设定说明，避免转发后丢失解释边界。
8. **重测控制**：保留答案补答、仅改一题、从头重测。补答应默认保留已答项；样例答案不应自动变成用户的正式答案。

## 可直接使用的中文组件文案

- 首页：“今天的你，属于哪一集？”
- 速测提示：“8 个离谱现场，先认领你的出场方式。”
- 补答按钮：“保留答案，再看另一面”
- 更新提示：“新情境加入，主角可能换位；之前的答案仍在。”
- 解释入口：“别只给我贴标签，说说证据”
- 近似双主角：“不是算法犹豫，是这两种风格离得很近。”（应同时显示实际接近分差，避免掩盖算法局限）
- 反差卡：“如果这集走了另一条路线”
- 搭子卡：“把你们放进同一个副本，会怎样？”
- 重测：“这次按真实反应，还是按理想人设？”（两者必须分开存档 / 标记，不能混淆结果）
- 分享尾注：“原创娱乐设定 · 接近分非心理结论 · 卡通形象与台词来源见说明”
